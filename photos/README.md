# Photos

Photos are linked to objects **by file name**, so there's no spreadsheet column to fill in.

| File name | Shows up as |
|---|---|
| `BENCH-04.jpg` | the main photo of BENCH-04 |
| `BENCH-04--2.jpg`, `BENCH-04--3.jpg` | extra photos of BENCH-04 |
| `BENCH-04--reference.jpg` | **how this area should be kept**: the "put it back like this" picture |
| `PED-01.D2.jpg` | what's in drawer PED-01.D2 |
| `I-0001.jpg` | item I-0001 |

## Rules

- The part before `--` must be an exact ID from `lab-data.xlsx` (placeables, services or items).
- Use `--` (two hyphens) before any suffix, because IDs contain single hyphens themselves.
- `.jpg`, `.jpeg`, `.png` and `.webp` all work. Drop phone photos in as they are: the directory will use
  shrunk copies, and the originals in this folder are never changed.

## Reference photos

Take them straight on, from where a person would stand, in good light, with the ID label visible.
Retake them whenever the agreed layout of that area changes.
